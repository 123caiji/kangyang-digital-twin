1. 目标应用是 Vue SPA，nginx 配置 `location / { try_files $uri $uri/ /index.html; }`，**任意不存在的路径都返回 200 + 1084 字节的 index.html**。扫描器看到 200 以为接口存在，实际拿到的是前端首页。

## 五、被验证有效的防护（继续保持）

1. **JWT 密钥已正确注入**：`server/.env` 中 `JWT_SECRET` 长度为 **64 位随机串**，未使用源码里的 `kangyang-dev-only-secret-...` 兜底值 → **无法伪造管理员令牌**。这是本次排查中最重要的一条好消息。
2. **API 认证中间件有效**：`middleware/auth.js` 对所有敏感路由强制 Bearer 校验，实测未授权访问全部 401。
3. **登录接口有多层防护**：
   - 图形验证码（3 分钟有效期，一次性消费）
   - 失败计数 + 账号锁定（触发 429，`lockUntil` 900 秒）
   - `bcryptjs` 密码哈希比对
   - JWT 有效期 8 小时
   - 实测攻击者 51 次登录尝试中有 4 次被 429 拦下 → **防护实际生效**
4. **`/assets/` 做了 `try_files $uri =404`**，不存在的静态资源不会落进 SPA 兜底。

## 六、整改清单（按优先级）

### P0 — 立即处理

**1. 收紧 SSH 爆破面（三选一，可叠加）**

| 方案 | 操作 | 副作用 |
|:---|:---|:---|
| A. 防火墙限制来源 IP | Lighthouse 防火墙把 22 端口 CIDR 从 `0.0.0.0/0` 改为你的固定 IP（如 `124.93.196.41/32`） | 换网络/移动办公时需临时放开 |
| B. 禁用密码登录改密钥 | 部署公钥后设 `PasswordAuthentication no` + `PermitRootLogin prohibit-password` | 需先配好密钥，否则会锁死自己 |
| C. 封禁攻击源 | 防火墙加一条 `51.222.47.156` 的 DROP | 治标，攻击者换 IP 即失效 |

> **推荐 A + 后续 B**。B 才是根治，但必须先确认密钥可用再改。

**2. 补一个快照**

该实例 **0 个快照**，而且 9-28 刚做过系统重置。现在处于「被攻击 + 无回滚点」的组合状态，任何误操作都不可逆。建议立刻创建 `bj-20260929-before-hardening`。

### P1 — 本周内

**3. `NODE_ENV` 改为 `production`**

`server/.env` 中当前为 `NODE_ENV=development`。生产环境跑开发模式的影响：
- `middleware/auth.js` 的密钥兜底告警不会触发
- 框架层可能向客户端返回详细错误栈（当前 500 响应体较小，暂未观察到堆栈泄露，但属隐患）
- 性能与日志行为均非生产最优

**4. 上传接口补文件头校验**

`server/routes/predict.js` 目前只用 `file.mimetype` 判断（客户端可任意伪造）。建议读文件前 12 字节比对 PNG/JPEG/GIF/WebP 魔数，不匹配直接拒绝并写审计日志。
> 好消息：`|` 第 19 行已做扩展名白名单，非白名单后缀会强制改写为 `.png`，所以不存在 `.php`/`.js` 落盘的问题。

**5. 吊销曾在公开仓库泄露的 LLM API Key**

`server/.env` 里你自己留了注释：

> `# ⚠️ 下面这个 key 已随公开仓库的历史提交泄露，请尽快到服务商后台吊销并更换`

**这条注释还挂在生产配置里，说明尚未处理。** 请到服务商后台吊销旧 key 并换新。仓库历史里的密钥不会因为删文件而消失，必须从服务商侧作废。

### P2 — 顺手清理

**6. 无效端口暴露**：防火墙放行了 `8080`（备注 kangyang-web），但**没有任何进程监听 8080**。要么是服务挂了，要么是历史遗留。建议确认后关掉这条规则。

**7. 443 同理**：防火墙放行了 `443`，但 nginx 只监听 `80`，**全站至今是 HTTP 明文**，登录密码在链路上裸奔。建议上 TLS 证书。

**8. 文件权限**：应用目录 `drwxrwxrwx`（777）、`server/.env` 为 `-rw-rw-rw-`（666）。上线产品不该是 anyone-writable，建议收紧为 `755` / `600`。

**9. 减少 SPA 误报噪音**：nginx 对未知路径返回 200，会持续吸引扫描器误判。可为非 `/api/`、非 `/assets/`、且带可疑后缀的请求直接返回 404。
